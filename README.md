# Mandi Connect

A web platform designed to connect farmers with verified traders through produce listings, competitive bidding, and mandi market price information.

## Current Progress

- React frontend initialized with Vite.
- Node.js and Express backend configured.
- Frontend successfully communicates with the backend health API.
- Basic project folder structure created.

## Technology Stack

- Frontend: React and Vite
- Backend: Node.js and Express
- Database: Azure SQL Database (planned)
- Cloud storage: Azure Blob Storage (planned)
- Analytics: Power BI (planned)

## Planned Features

- Farmer and trader accounts
- Produce listings
- Competitive bidding
- Official mandi price information
- Transport booking records
- Market price analytics
- Role-based access control

Phase 1: Initial project setup and frontend-backend connectivity completed.
